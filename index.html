      Cómo se juega

      1. Pasaos el móvil. Cada jugador ve en secreto la palabra… salvo el infiltrado, que no la sabe.
      2. Por turnos, cada uno dice una sola palabra relacionada. Si eres el infiltrado, disimula e intenta deducirla.
      3. Cuando acabe el tiempo (o antes), votad a la vez quién creéis que es.
      4. Si pilláis al infiltrado, aún puede salvarse adivinando la palabra.

      Puntos

      • Pilláis al infiltrado y falla: +1 para cada jugador normal.
      • Le pilláis pero acierta la palabra: +2 para el infiltrado.
      • El infiltrado no es descubierto: +3 para él.
