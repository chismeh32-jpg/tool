🛟 Punto de restauración

Es una «foto» de la configuración de Windows. Si algo fuera mal, puedes volver a ella desde Configuración → Sistema → Recuperación. ToolBox te ofrece crear uno antes de cada cambio importante.

🧹 Limpieza

Primero analizamos cuánto ocupa cada cosa (no se borra nada). Luego eliges qué limpiar. Las marcadas como Seguro se pueden borrar siempre.

Pulsa «Analizar» para ver cuánto espacio puedes recuperar.

📦 Instalar apps

Marca los programas que quieras y pulsa «Instalar». Se descargan de sus webs oficiales a través de winget, el instalador oficial de Microsoft, y se instalan sin preguntas.

⚠ No encontramos winget en este PC. Instala «Instalador de aplicación» desde Microsoft Store y vuelve a abrir ToolBox.

🧽 Desinstalar

Quita programas sin dejar restos y las apps que Windows trae de serie.

Primero se abre el desinstalador oficial del programa. Cuando termine, ToolBox busca lo que haya dejado (carpetas y registro) y te lo enseña antes de borrar nada. Las carpetas van a la Papelera y del registro se guarda una copia.
